# public-Doc — EzPrint Public Documentation

Website tài liệu công khai cho EzPrint / SPXExpress Lâm Đồng.

## Website

Website được xuất bản bằng GitHub Pages từ nhánh `main` của repository này. Đường dẫn website được quản lý trong phần cài đặt Pages của repository.

## Cấu trúc

- `index.html` — Trang chủ và thư viện tài liệu.
- `privacy-policy.html` — Trang Privacy Policy.
- `docs/PRIVACY-POLICY.md` — Nội dung chính sách Markdown.
- `docs/USER-GUIDE.md` — Hướng dẫn sử dụng.
- `docs/OPERATIONS-GUIDE.md` — Hướng dẫn vận hành.
- `docs/TESTING-GUIDE.md` — Hướng dẫn thử nghiệm.
- `docs/ABOUT-EZPRINT.md` — Giới thiệu công cụ.
- `docs/CHANGELOG.md` — Lịch sử phiên bản công khai.

## GitHub Pages

Repository Settings → Pages → Build and deployment → Deploy from a branch → Branch: `main` → Folder: `/ (root)` → Save.

## Public data boundary

Only prepared public-facing documents are included. Do not upload extension source, AI collaboration logs, raw HAR captures, shipment/customer records, credentials, tokens, cookies, endpoint addresses, network identifiers, or internal operational logs.
