# EzPrint — Lịch sử phiên bản công khai

## v2.0.4 Experimental

- Đồng bộ nhận diện EzPrint và phiên bản hiển thị.
- Tối ưu giao diện Side Panel theo kích thước hẹp và thấp.
- Cải thiện quy trình tra cứu trạng thái thực từ API FMS.
